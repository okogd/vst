# RiserLab (VST3, 64-bit, stereo)
Reverse-riser для вокала: пишет вход, играет его задом наперёд по темпу хоста, поднимает high-pass (райзер), опционально тремоло.

## Как получить .vst3 без установки компилятора
1. Создай бесплатный аккаунт на github.com, New repository (любое имя).
2. Загрузи туда ВСЕ файлы из этой папки (с папками Source и .github).
3. Вкладка Actions -> дождись зелёной галки (5-10 мин).
4. Внутри запуска внизу Artifacts -> RiserLab-VST3-x64 -> скачай и распакуй.
5. Положи папку RiserLab.vst3 в C:\Program Files\Common Files\VST3 и пересканируй плагины в DAW.
